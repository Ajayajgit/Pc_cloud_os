## 2. Logo

### Versions Available
| Usage | Description |
|---|---|
| **Primary** | Full color logo (cloud symbol + "Power Cloud" wordmark + "CONSULTING" in green) on light background |
| **Secondary** | Reversed/white version for dark backgrounds |
| **Symbol only** | Cloud icon without wordmark — used for social media avatars and small placements |
| **Monotone** | Black or white single-color version |

### Logo Construction
- The logo consists of a **blue cloud icon** with a **green triangle/arrow element** at the base
- Wordmark: **"Power Cloud"** in bold white/dark sans-serif
- Sub-brand word: **"CONSULTING"** in spaced green capitals (letterspaced)

### Clear Space Rule
- Maintain clear space equal to **50% of the logo symbol height** on all four sides
- Never crowd the logo with other elements

### Background Rules
- **Light backgrounds:** Use primary (full color, dark text) version
- **Dark backgrounds:** Use secondary (white text) version
- **Never** place the logo on backgrounds that create poor contrast

### Logo Don'ts
- Do NOT distort, stretch, or rotate the logo
- Do NOT apply drop shadows or effects
- Do NOT change logo colors
- Do NOT place on busy/cluttered backgrounds
- Do NOT use on bright green or lime backgrounds (clashes with brand colors)
- Do NOT use low-resolution versions

### Digital Dimensions
| Placement | Size |
|---|---|
| Website header/nav | 250 × 100 px |
| Favicon | 16×16, 32×32, 48×48 px |
| Email signature | 300 × 100 px |
| Presentation slide | 800 × 200 px |
| Social profile picture | 400 × 400 px (Twitter/LinkedIn), 180 × 180 px (Facebook) |
| App icon (iOS) | 180 × 180 px |
| App icon (Android) | 192 × 192 px |

### Logo Placement on Creatives
- Social media creatives and digital ads: **top right corner**
- Both full logo and symbol-only versions should default to top right placement

### Preferred File Formats
- **SVG** — preferred for all digital/web (scales without quality loss)
- **PNG** — for raster with transparency
- **JPG** — for non-transparent backgrounds only (use high resolution)

## 4. Typography

### Primary Font — Montserrat
**Use for:** All headings, subheadings, titles, navigation, slide titles, section headers

| Weight | Use Case |
|---|---|
| Regular | Light headlines, introductory text |
| Medium | Secondary headings |
| SemiBold | Subheadings, emphasized labels |
| Bold | Primary headings, hero text, titles |

- Available free via Google Fonts
- Excellent readability at all sizes and in print
- Modern, clean, sans-serif — conveys trust and clarity

### Secondary Font — Barlow
**Use for:** Body copy, paragraphs, descriptions, captions, UI text

| Weight | Use Case |
|---|---|
| Regular | Standard body copy |
| Medium | Emphasized body text |
| SemiBold | Labels, callout text |
| Bold | Strong emphasis within body |

- Available free via Google Fonts
- Superfamily with condensed/semi-condensed variants
- Highly legible at small sizes — ideal for UI and app interfaces

### Typography Rules
- **Never** use decorative, script, or serif fonts in brand materials
- Maintain strong typographic hierarchy: large bold Montserrat headings → medium Barlow body
- Use generous line-height for body text (1.5–1.6)
- Letter-spacing on "CONSULTING" label in logo is wide/tracked — replicate this style for sub-labels in spaced caps

## 5. Imagery

### Approved Image Style
Use **high-quality, professional photography and 3D renders** that align with:
- Enterprise technology / cloud computing (glowing data, servers, network visuals)
- Professional business people (confident, collaborative, diverse)
- Team collaboration scenes (whiteboard sessions, laptops, meetings)
- Abstract tech backgrounds (blue/dark tones with light streaks — matches brand palette)

### Approved Vector/Illustration Style
Two styles are approved:
1. **Isometric vectors** — 3D-perspective flat illustrations showing tech ecosystems, cloud infrastructure, workflows
2. **Flat 2D vectors** — Clean, friendly character-based illustrations showing business interactions

### Image Don'ts — Strictly Avoid
| Type | Reason |
|---|---|
| Cartoonish clip art | Too informal, off-brand |
| Abstract cluttered tech collages | Confusing, low quality look |
| Blurred or low-resolution images | Unprofessional |
| Watermarked/stock images with visible marks | Unprofessional |
| Bright/colorful abstract artworks | Clashes with brand palette |
| Images inconsistent with blue/dark brand palette | Breaks visual consistency |

## 6. Icons

### Approved Icon Styles
Two styles are approved — choose one and use consistently within a single asset:

1. **Outline style** — line-art icons, thin strokes, Sky Blue (`#31A4F3`) color
2. **Filled style** — solid filled icons, Sky Blue (`#31A4F3`) color

### Icon Rules
- Always use icons in brand blue (`#31A4F3`) or white — no other colors
- Icons should be simple, universally recognizable
- Consistent style throughout any single document or UI
- Preferred icon categories: cloud, data, analytics, gears/settings, documents, connectivity

## 7. Design System — Layouts & Backgrounds

### Dark Theme (Primary)
- Background: `#1E1E1E` or `#002F59` (Deep Blue)
- Text: `#FFFFFF`
- Accents: `#31A4F3` (Sky Blue), `#41B946` (Green)
- Used for: Hero sections, title slides, dark-mode UIs

### Light Theme (Secondary)
- Background: `#FFFFFF` or light gray (`#F5F5F5`)
- Text: `#1E1E1E`
- Accents: `#31A4F3`, `#41B946`
- Used for: Documents, body content slides, print materials

### Gradient Backgrounds
Dark-to-teal/blue gradients are a core brand visual element — seen in section dividers and hero slides. Example:
```
background: linear-gradient(135deg, #1a1a2e 0%, #002F59 50%, #31A4F3 100%);
```

### Brand Visual Motif
The brand frequently uses **light streak / speed line photography** (cyan/blue light trails on black backgrounds) as a hero background. This conveys speed, innovation, and forward momentum. Use sparingly and only in large-format hero areas.

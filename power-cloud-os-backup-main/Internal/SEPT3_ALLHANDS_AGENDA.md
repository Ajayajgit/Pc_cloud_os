## The announcements (1:10 segment, scripted)

1. **The OS moved.** "The OS now lives at `G:\Shared drives\Power Cloud OS`, its own shared drive, everything at the root. The old `Power Cloud Project Folders\Power Cloud OS` path is dead. Update pinned shortcuts today; the old drive stays as the read-only legacy annex for historical client folders."
2. **The deck is the Presentation, not the Proposal.** "We already have the work; the deck walks the client through findings. Filenames and documents now say Presentation."
3. **Exec summaries are always human-reviewed. Permanent policy.** "No exec summary reaches a client without a consultant reading and approving it first. Not a training-wheels phase."
4. **Client approval before build, dev review before testing.** "No build starts until client approval is verified on the referenced Asana task; an email approval gets pasted onto the task with the source cited. Scripted work gets a dev-team review before it comes back to you for testing. The rule applies now; the tool will enforce the gate soon." (Announce as policy in effect by convention. Do NOT present it as mechanically enforced; the gate is not built yet.)
5. **Hours in exec summaries lag up to a week.** "Each client folder gets a weekly hours log from the Monday job, so summaries read hours locally. The narrative is live to the minute; the hours window stops at the last completed Sunday. Never read a Friday summary's hours as current." (If the A16 deploy is not verified by Sept 3, say "rolling out this month" rather than "live.")
6. **Feedback: when the tool annoys you, say so.** "Type `/feedback` or say 'log this as feedback' in any session; Claude writes the entry from what just happened. Everything gets triaged; nothing is silently deleted. The tool only improves from what gets reported."
7. **Session norms, the three that matter most.** "One task, one session, started inside the client's folder. Name sessions client + environment; paste the /rename line. You don't need the frontier model to write a PDF; escalate only when the default fails, and check your effort setting when a session feels slow. Hitting the $25 monthly credit limit is a signal, not a failure; tell Mike."

By end of next week, every consultant: (1) step zero verified on their machine (already a prerequisite for today), (2) one real task run through the OS in a properly named session from a client folder, (3) at least one `/feedback` entry if anything got in the way. "Proofread everything before it leaves the building; 'the AI wrote it' is the failure, not the defense."
